# LQ-Rechner (Basisversion)

Kostenlose Webversion des LQ-Rechners für die Radioonkologie: BED, EQD2, Isoeffekt-Umrechnung, α/β-Referenz.

Live: https://dansparker.github.io/radonc/

Die Vollversion (Summation, Re-Bestrahlung, Pausenplanung, Toleranzen, Brachytherapie, DVH, TCP/NTCP) gibt es als Android-App „LQ-Rechner“ bei Google Play.

Lehr- und Ausbildungswerkzeug – nicht für Therapieentscheidungen bestimmt.
